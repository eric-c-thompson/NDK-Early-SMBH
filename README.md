## Overview
This repository contains the manuscript, figures, and Python source code for the cosmological predictions of the **Null-Directional Kinematics (NDK)** framework. 

Standard cosmological models face increasing tension in explaining the rapid assembly of supermassive black holes (SMBHs) at very high redshifts ($z \gtrsim 8$), as observed by JWST. This paper offers a purely kinematic solution: black hole formation is interpreted as a **kinematic saturation event** occurring when the coarse-grained null-directional strain exceeds a critical threshold, rather than a product of prolonged Eddington-limited accretion.

## Core Cosmological Predictions

**1. The Absolute Kinematic Ceiling**
The framework predicts a redshift-dependent kinematic support boundary set by the Hubble-horizon mass scale:
$$M_H(z) = \frac{c^3}{G H(z)}$$
This represents the absolute maximum causal coherence limit for direct kinematic saturation.

**2. The Rare-Event Capacity Envelope**
While $M_H(z)$ is the absolute ceiling, the operational observational boundary is a lower envelope, $M_{\rm env}(z)$, governed by the extreme Gaussian tail of primordial fluctuation statistics. This model successfully encompasses reported high-redshift black-hole candidates (e.g., GN-z11, UHZ1, J0313-1806) as extreme-tail formation events.

**3. Strict Falsifiability**
Because the operational envelope is constructed as a conservative upper-capacity bound, a statistically robust population of high-redshift black hole mass estimates lying *above* this predicted envelope would formally falsify this single-anchor Gaussian-tail realization of the NDK framework.

## Repository Structure
* `/paper`: Contains the LaTeX source code (`.tex`) and the compiled `.pdf` of the manuscript.
* `/code`: Contains the Jupyter Notebook (`.ipynb`) used to compute the linear-theory variance and plot the kinematic saturation envelope against JWST observational data.
* `/figures`: Contains the exported high-resolution graph generated by the code.

## Running the Code
The analysis code is provided as a Jupyter Notebook. It requires the following Python libraries:
* `numpy`
* `matplotlib`
* `scipy`
* `astropy`
* `colossus` (used to compute the linear matter variance $\sigma(R,z)$ using Planck18 parameters).

The notebook is configured to quietly install `colossus` if run in a Google Colab environment.
